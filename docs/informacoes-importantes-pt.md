# Informações importantes

Esta página reúne informações essenciais sobre o uso da plataforma GEMIBRA.

## Uso dos dados
- Os dados disponibilizados têm finalidade científica e de vigilância em saúde.
- Sempre cite o projeto GEMIBRA ao utilizar os dados em análises, relatórios ou publicações.

## Atualizações
- O banco de dados é atualizado periodicamente.
- Verifique as datas de atualização e a versão do conjunto de dados antes de iniciar novas análises.

## Qualidade e interpretação
- Os dados são agregados de bases públicas e podem conter limitações de origem.
- A interpretação dos resultados deve considerar contexto clínico, epidemiológico e metodológico.
