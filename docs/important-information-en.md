# Important information

This page provides essential guidance for using the GEMIBRA platform.

## Data usage
- The available data is intended for scientific and public health surveillance purposes.
- Please cite the GEMIBRA project when using the data in analyses, reports, or publications.

## Updates
- The database is updated periodically.
- Always check dataset version and update date before starting new analyses.

## Data quality and interpretation
- Data is aggregated from public sources and may include source-related limitations.
- Results should be interpreted within clinical, epidemiological, and methodological context.
